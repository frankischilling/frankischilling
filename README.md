## About me

I'm Frank, an Information Technology student at Wentworth Institute of Technology and an IT technician. Outside of work and school, I spend a lot of time with GNU/Linux, systems programming, and retro consoles. I like understanding how the software I use works, which often means reading its source code and working through the details myself.

My projects cover operating systems, emulation, compilers, and game decompilation. I work with C, C++, Rust, and OCaml, and I also build web applications and smaller desktop tools.

### A few things I'm working on

- [Axiom64](https://github.com/frankischilling/Axiom64): a 64-bit operating system written in C++ and Assembly.
- [holyc-ocaml](https://github.com/frankischilling/holyc-ocaml): a HolyC compiler written in OCaml, using the TempleOS source as its reference.
- [robotron64](https://github.com/frankischilling/robotron64): working toward a byte-matching C decompilation of Robotron 64 for the Nintendo 64.

I also work on [NES](https://github.com/cupidthecat/cupid-nes) and [Nintendo 64](https://github.com/cupidthecat/cupid-n64) emulation. Some of my console work involves improving or restoring existing Xbox 360 ports, including [snes360-enhanced](https://github.com/frankischilling/snes360-enhanced), [fce360-enhanced](https://github.com/frankischilling/fce360-enhanced), and [vba360-enhanced](https://github.com/frankischilling/vba360-enhanced).

My Linux projects include work on [terminal tools](https://github.com/cupidthecat/cupidterminal), [file managers](https://github.com/cupidthecat/cupidfm), and [shells](https://github.com/cupidthecat/cherubsh). For web development, I'm building [26chan](https://github.com/frankischilling/26chan), an imageboard written in Rust.
